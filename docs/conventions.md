# ドキュメントの規約

## 形式

`docs/` 配下は [OKF v0.2](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/6886cc67650de5600a579ebbd1b164e32f9f356d/okf/SPEC.md) に加えて、次のルールで書く。

- 出典は frontmatter の `sources` に書き、本文からは脚注（`[^id]`）で参照する。
- ドキュメント間のリンクは相対パスで書く（OKF はルートからの絶対パスを推奨しているが、GitHub 上で表示したときにリンクが切れるため）。

## 凡例

- 印なし … 決定事項。MVP に限らず、将来を見据えた判断
- **[MVP]** … MVP として暫定的に決めていること。後のフェーズで見直す前提
- **[未決]** … まだ決めていないこと（MVP では不要なため後回しにしているものを含む）

## 但し書き

決定事項は「現時点での合意」を意味し、永久に固定するものではない。開発を進める中で前提や判断が変われば見直す。見直したときはドキュメントを更新し、変更の理由を [変更履歴](log.md) に残す。
